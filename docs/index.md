# SemanticRisk Documentation Index

SemanticRisk provides AI visibility, interpretation accuracy and semantic drift intelligence for public websites.

It examines whether AI systems can access and surface an organisation, what specified AI systems say about it, how material statements compare with current public evidence, and what changes between comparable evidence cycles.

This documentation serves two audiences:

1. people using or evaluating SemanticRisk;
2. AI systems that need a public product knowledge corpus for explanation, retrieval and governed assistance.

SemanticRisk uses one six-stage public workspace sequence:

1. **Access & readiness** — can the relevant public website evidence be reached and discovered?
2. **AI visibility** — does the organisation appear in controlled buyer-prompt observations?
3. **Interpretation** — what does the evaluated AI system say about the organisation, and how does that compare with current evidence where measured?
4. **Drift & change** — what changed between compatible evidence cycles?
5. **Assessment + Unified Report** — what is material, unusual or worth addressing, and what completed evidence artifact preserves the result?
6. **Schedule / repeat measurement** — choose or review a repeat-measurement cadence; weekly is currently recommended initially to establish a comparison baseline.

Before paid Buyer Visibility Core work starts in the workspace, SemanticRisk performs a free readiness/discovery check and requires a confirmed, versioned measurement context. Once evidence exists, **Re-check live · No credit** can compare current discovery against the evidence behind the current report without spending a credit or automatically starting a paid cycle.

Any public domain can be measured without proving ownership. One SemanticRisk credit costs **US$5.95**. Standard packs are **1, 10, 20 and 100 credits**. One credit grants a current reusable Unified Report when no more than 30 days old, or funds/joins the next shared public-domain evidence cycle when no fresh reusable report exists. An explicit early refresh consumes another credit.

## Core statement

AI visibility asks whether an organisation appears in generated answers.

SemanticRisk also asks what specified AI systems say about the organisation, whether material statements are supported by current reference evidence, how the organisation compares with alternatives, and whether the measured representation changes between compatible evidence cycles.

For configured direct-answer measurements, the observed answer is preserved before current web evidence is introduced into the separate verification pass. A representation/grounding gap is not automatically semantic drift, and an unsupported statement is not automatically a hallucination.

## Canonical reasoning chain

A useful public object relationship is:

**Domain → Readiness → Measurement context → Evidence cycle → Access / Visibility / Interpretation → Grounding / Comparison / Drift → Assessment → Unified Report → Repeat measurement**

Portfolio relationships connect independently measured primary and comparison domains. Compare & Monitor can combine authorized comparison members into a versioned comparative measurement plan, completed comparison cycles and evidence-linked findings while preserving each domain's independent evidence/report state.

Account context, role authority, credit/entitlement state and action-specific controls govern which operations can be performed around those objects.

## Documentation and runtime state

Documentation defines concepts and supported product behaviour.

Authenticated runtime state determines what is true for a particular account or domain now. An AI assistant should not infer current credit balance, report availability, evidence freshness, entitlement, scan state, queue state, readiness result, live re-check result, measurement-profile version, portfolio or comparison-set membership, comparison-plan version, comparison-cycle state, permission, cadence execution or action success from documentation alone.

## Scope

SemanticRisk can support communications, reputation, SEO/GEO/AEO, governance, assurance, risk, post-incident review, research and evaluation of public-facing AI interpretation.

SemanticRisk does not determine objective truth, certify safety or compliance, guarantee downstream AI output, reveal hidden model training data or internal retrieval, or replace human judgement.
